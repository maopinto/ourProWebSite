# TERRA — HTML, CSS ו־JavaScript

האתר בנוי מקבצים רגילים שהדפדפן יודע לפתוח. אין צורך ב־React, ב־TypeScript, ב־Node.js, בהתקנת חבילות או בפקודות בנייה.

## פתיחה עם Live Server

1. פותחים את תיקיית האתר ב־VS Code.
2. לוחצים לחיצה ימנית על `index.html` בתיקייה הראשית.
3. בוחרים **Open with Live Server**.
4. עורכים ושומרים קובץ — הדפדפן מתעדכן אוטומטית.

אם האפשרות לא מופיעה, מתקינים ב־VS Code את תוסף **Live Server** של **Ritwick Dey**.
אפשר גם לפתוח את `index.html` ישירות בדפדפן; Live Server מוסיף רענון אוטומטי בזמן העבודה.

## איפה עורכים?

| קובץ | מה הוא מכיל |
| --- | --- |
| `index.html` | כל מבנה העמוד: טקסטים, כותרות, כפתורים, אזורים וחלונות |
| `styles.css` | עיצוב: צבעים, גדלים, מרווחים, אנימציות והתאמה לטלפון |
| `js/main.js` | פעולות העמוד: תפריט, בחירת נוף, דוגמאות טקסט ומסך מלא |
| `js/dialogs.js` | חלונות החשבון וההורדה |
| `js/terrain.js` | ציור הנוף התלת־ממדי ב־WebGL וסיבובו בעכבר או במקלדת |
| `favicon.svg` | הסמל בלשונית הדפדפן |

למשל: כדי לשנות את הכותרת הראשית, מחפשים `A world of` בתוך `index.html` ומשנים את הטקסט.
את שלוש דוגמאות הטקסט המתחלפות עורכים במערך `landscapes` בתחילת `js/main.js`; הטקסט הראשוני מופיע גם ב־`index.html`.

קבצי ה־JavaScript מחולקים לפי תפקיד כדי שיהיה קל למצוא מה לשנות. הם נטענים ישירות מה־HTML, ללא ספריות חיצוניות.
האתר משתמש בגופנים מ־Google Fonts עם גופני מערכת חלופיים כאשר אין אינטרנט.

## מה עובד באתר?

התפריט, החלונות, בחירת הנוף, סיבוב התצוגה, מצב רשת ומסך מלא עובדים בדפדפן. דוגמאות הטקסט הן לקריאה בלבד; הן אינן שולחות בקשות ל־AI או יוצרות עולמות באתר.

טופסי החשבון הם הדגמה בלבד ואינם שולחים או שומרים פרטים. ההורדה מציגה **Coming soon**, כי עדיין אין קובץ התקנה. כדי להפעיל התחברות והורדות אמיתיות בהמשך, צריך לחבר שירות חשבונות וקישורים לקובצי ההתקנה.

## העלאה לאחסון

מעלים יחד את `index.html`, את `styles.css`, את `favicon.svg` ואת תיקיית `js`. אין שלב בנייה. הנתיבים יחסיים, כך שאפשר לאחסן את האתר גם בתת־תיקייה.

תיקיית `.verification` מכילה כלי בדיקה, תמונות בדיקה וקובצי עזר שנשמרו מהגרסה הקודמת; היא אינה חלק מהאתר ואין צורך להעלות אותה.
